## Get Dopa Shopify Theme Work

### Challenge
Get Dopa needed a campaign-led PDP experience that could convert effectively on mobile while handling complex interactive sections and review content.

### Approach
- Built a campaign-focused product page structure across hero, ingredients, and social-proof modules.
- Implemented Reviews.io rating components and tuned star rendering logic for campaign PDP variants.
- Improved fixed add-to-cart behavior, sticky gallery behavior, and thumbnail navigation for small screens.
- Fixed carousel gesture and scroll-lock conflicts to reduce accidental horizontal scrolling.

### Outcome
The storefront gained a more consistent campaign PDP journey and a smoother mobile purchase path with fewer interaction edge cases.

### Stack
Shopify Liquid, JavaScript, Reviews.io integration, responsive UI implementation.
